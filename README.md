# OpenClaw Hardware Integration Monitor

## Overview
This repository contains a real-time monitoring dashboard for OpenClaw hardware integration projects across edge hardware platforms.

**Scope: Edge Hardware Only** — Pure PC/Cloud/Server projects are excluded.

## Monitoring Keywords
arduino, raspberry pi, jetson, esp32, xiao, e-ink, iot, robotic, home assistant

## Platform Coverage
- **Microcontrollers**: ESP32, XIAO (Seeed), Arduino, RISC-V, Pico, M5Stack
- **Single Board Computers**: Raspberry Pi, NVIDIA Jetson (Orin), Sipeed
- **Display**: E-Ink, IoT displays
- **Robotics**: Reachy Mini, Robot, Humanoid, Quadruped
- **AI Compute**: NVIDIA Jetson, Orin, DGX Spark
- **IoT & Home Assistant**: IoT integrations, Home Assistant ecosystem

## Key Projects

### Core Ecosystem
- **Official OpenClaw**: 251k+ stars - The main AI assistant framework
- **Picoclaw (Sipeed)**: 21.8k stars - Tiny, fast, deployable anywhere
- **MimiClaw**: 3.7k stars - Run OpenClaw on $5 chips

### Hardware Platforms
- **ESP32/XIAO**: Multiple IoT agent implementations
- **Raspberry Pi**: Full system installations and lightweight agents  
- **NVIDIA Jetson**: AI compute platform integrations
- **Arduino**: Code generation and maker skills

### Specialized Projects
- **WireClaw**: ESP32 AI agent with offline rule engine
- **OpenClawgotchi**: AI Tamagotchi with E-Ink display
- **Monagotchi**: ESP32 + memecoin integration
- **Reachy Mini**: Robotics integration

## Usage
Visit the live dashboard at: https://256ericpan.github.io/clawhardware/

Features:
- Filter by application category (Robotics, IoT, Embedded, Maker, AI Compute)
- Filter by technology platform (ESP32, Arduino, Raspberry Pi, Jetson)
- Search by project name or description
- Sort by GitHub stars (descending)
- View product links and hardware specifications

## Data Sources
- GitHub API for repository metadata
- Manual curation of hardware product links
- Community project discovery through keyword searches

## Scope Boundary
- ✅ Edge hardware: ESP32, Raspberry Pi, Jetson, Arduino, XIAO, E-Ink, IoT, robotics
- ❌ Excluded: Pure PC, Mac, Windows, Desktop, Server, Cloud, Mobile-only projects

## Contributing
New projects are automatically discovered through regular monitoring. If you have a project that should be included, please ensure it has "openclaw" in the repository name or description and targets edge hardware.
